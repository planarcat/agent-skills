# DESIGN.md 骨架模板

新项目起手时，把下面整段复制成项目根的 `DESIGN.md`，然后逐项填值。
**填不出的先留 `<待定>`，不要编。**

---

```markdown
# <项目名> · 设计规范（DESIGN.md）

> 本文件是本项目的**视觉唯一真源**。改界面前先读它。
> 配套：`AGENTS.md`（自动加载的硬规则，指向本文件）· `tokens.css`（值）· `scripts/lint_styles.py`（机检）

## 0. 场景基调与读法

### 0.1 场景基调

本项目是 **<工具型应用 / 展示型站点 / 两者混合>**：

| 旋钮 | 取值 | 含义 |
|---|---|---|
| 布局变化度 | <3> / 10 | <同类页面保持一致 / 每页可不同> |
| 动效强度 | <2> / 10 | <只解释状态变化 / 可营造氛围> |
| 信息密度 | <8> / 10 | <一屏尽量多信息 / 留白为主> |

**这条决定取舍**：<例如"凡是让每页更不一样的建议在这里是反作用">

### 0.2 读法

1. 颜色 / 字号 / 间距 / 圆角 / 阴影 / 动效**只用 `tokens.css` 的变量**，不写裸值。
2. 交互反馈走统一组件，禁原生 `alert/confirm/prompt`。
3. 交活前跑 `python3 scripts/lint_styles.py`，必须 PASSED。
4. 拿不准先看本文件 §7 禁止项。

## 1. 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--c-ink` ~ `--c-ink-4` | <填> | 文本阶梯，主 → 弱 |
| `--c-bg` / `--c-surface` / `--c-surface-2` | <填> | 底 / 面板 / 卡片 |
| `--c-line` | <填> | 发丝分隔线（1px） |
| `--c-accent` | <填> | **唯一强调色**：主操作、激活、链接 |
| `--c-ok` / `--c-warn` / `--c-err` | <填> | 语义三态，只用于反馈 |

规则：一屏内强调色元素 ≤2 处；语义色不做装饰；不靠颜色单独传信息。

## 2. 字号阶梯（仅 N 档）

| Token | 值 | 用途 |
|---|---|---|
| `--fs-xs` | <填> | 微标注、时间戳 |
| `--fs-s` | <填> | 标签、徽章 |
| `--fs-body` | <填> | 正文基准 |
| `--fs-m` | <填> | 列表主字 |
| `--fs-l` | <填> | 卡片标题 |
| `--fs-xl` | <填> | 视图标题 |

规则：不新增档位；正文行高 1.5–1.6。

## 3. 间距（8pt 网格）

`--sp-1:4 · --sp-2:8 · --sp-3:12 · --sp-4:16 · --sp-5:24 · --sp-6:32`

规则：所有内外边距与间隔从中取；布局尺寸（栏宽、栅格）可用具体 px。

## 4. 圆角、层级、阴影、动效

- 圆角仅 3 档：`--r-s` / `--r-m` / `--r-l`，按"微元素 / 交互 / 容器"分工；同一层级必须同值。
- 圆角容器必须 `overflow: hidden`（否则子元素方角顶破外层）。
- 层级：`--z-dropdown` / `--z-modal` / `--z-toast`，不写魔法数字。
- 阴影：`--sh-hover` / `--sh-active` / `--sh-float` 三档，不手写数值。
- 动效：<150 / 250 / 300ms> 三档 + 统一曲线；展开用 `grid-template-rows: 0fr → 1fr`。

## 5. 反馈与交互规范

| 场景 | 做法 |
|---|---|
| 操作成功 / 失败 / 警告 | 统一 toast，右下角，自动消失 |
| 危险操作 | 二次确认弹窗，主按钮用危险色 |
| 异步进行中 | 按钮 loading + 禁用 |
| 列表为空 | 空态：图标 + 一句话 + 主 CTA |
| 数据加载 | **骨架屏**，不全屏 spinner |

规则：禁原生 `alert/confirm/prompt`；错误信息说明原因 + 建议。
```

## 配套还要生成

1. **`AGENTS.md`**（或 `CLAUDE.md`）—— 6 行硬规则，指向 DESIGN.md，不复制 token 值
2. **`tokens.css`** —— 上面所有值在这里定义一次
3. **`scripts/lint_styles.py`** —— 从 skill 的 `scripts/` 复制过来
4. **`.git/hooks/pre-commit`**（可选）—— 提交时自动跑 lint：
   ```sh
   #!/bin/sh
   python3 scripts/lint_styles.py --dir web || exit 1
   ```
   （`chmod +x .git/hooks/pre-commit`）
