# 方案画廊：第 ③ 步「找方向」的跨工具做法

## 为什么需要这个

"生成多版方案让人挑选"这件事，**不应该依赖任何工具的内置命令**——内置命令只在特定工具里存在，换个工具就没了。

正确做法是把它还原成最朴素的形态：**生成几个独立 HTML + 一个对比页**。纯文件操作，任何能写文件的 agent 都能做。

| 路径 | 前提 | 适用 |
|---|---|---|
| **自建画廊**（本文） | 无——任何工具都能写文件 | **默认走这条，全工具通用** |
| Claude Code `/design` | 只有 Claude Code 有，且是预览功能 | 恰好用 Claude Code 时可以更省事 |
| `cc-design-cli` | 要 `npx` + 常驻 MCP | 想要更精细的画廊交互时 |

## 标准做法（四步）

### 1. 生成方案

在某目录下建 `方案/`，生成 **3–4 版**，每版一个**自包含单文件 HTML**：

```
方案/
├── 01-极简.html
├── 02-编辑风.html
├── 03-数据密集.html
└── 04-卡片式.html
```

文件名规则：`<序号>-<风格名>.html`（序号必须数字开头，脚本据此提取风格名）。

### 2. 生成对比页

```bash
python3 <skill>/scripts/make_gallery.py --dir 方案 --title "XX 页方案对比"
```

输出 `方案/对比.html`：所有方案并排 iframe 展示，点标题可新窗口打开。

### 3. 人挑选

打开对比页 → 并排看 → 告诉 AI 结果，例如：

- "选 2 号"
- "选 2 号，但把间距放松一点"
- "2 号的骨架 + 3 号的密度，再来一版"

### 4. 进第 ④ 步

选定的那版 → **固化成 `tokens.css` 与 `DESIGN.md`** → 再实现。
不要直接拿方案 HTML 当成品（它只是方向示意）。

## 方案 HTML 的质量要求（关键）

差劲的方案会让人挑不出东西。每版必须满足：

| 要求 | 说明 |
|---|---|
| **能打开的真实界面** | 是渲染出来的界面，不是文字描述或线框图 |
| **3–4 版有真实差异** | 结构、密度、气质上的差别；**不是同一套换个颜色** |
| **内容真实或合理占位** | 用项目的真实文案或像样的占位，**禁用 lorem ipsum** |
| **遵守项目场景基调** | 工具型界面不要加氛围动效和破格布局（见 `tone-lock.md`） |
| **单文件自包含** | 样式内联或写在 `<style>` 里，能离线双击打开 |
| **覆盖主要状态** | 至少演示主视图；有列表的给一行数据，别只给空壳 |

## 方案要有差异，靠的是什么

按这几个维度拉开，比"换配色"有效得多：

1. **信息密度**：一屏放 5 条还是 15 条
2. **导航形态**：顶部栏 / 侧栏 / 混合
3. **层级表达**：靠分隔线、靠底色、靠留白
4. **主次关系**：主操作在哪、多大
5. **内容组织**：列表 / 表格 / 卡片流

**同一个需求的 3 版应该像 3 个不同产品的界面**，而不是同一版换了三个主题色。

### 一种经过验证的分法：按密度分三档

外部的成熟同类 skill（`ui-redesign`，312 条规则 + 6 道门禁）用的就是这个套路——一次出 **3 版**，只让**密度**这一个维度变化：

| 版 | 特征 |
|---|---|
| 高密度版 | 一屏塞最多信息，紧凑行距、发丝线分隔 |
| 均衡版 | 常规间距，主次分明 |
| 流式版 | 宽松留白，重点突出 |

配合 `tone-lock.md` 的密度旋钮使用：基调定了"密度 8"，三版可取 **6 / 8 / 9**。
**只变一个维度**的好处是差异清晰、便于比较；全都乱变会让人挑花眼却说不出好在哪。

> 它生成原型的方式与本 skill 的 `make_gallery.py` 是**同一机制**（多版 HTML + 一个 index 页挑方向），
> 说明"多版并排挑选"是这类问题的通用解法，不是某家工具的特有功能。

## 挑选后的动作

1. 把选定方向的**关键决策**写进 `DESIGN.md`（为什么选它、放弃了什么）
2. 把它的**值**翻译成 token 写进 `tokens.css`
3. 未选中的方案可以删掉，或留作后续参考

第 1 条尤其重要：**"放弃了什么"才是规范里最有价值的部分**——那是别人抄不走的取舍记录。
