# 通用禁止项（anti-patterns）

跨项目都成立的界面反模式。项目自己的 `DESIGN.md` 可以增补，**但不应删减**——这些都是踩过的坑。

🤖 = 可用 `scripts/lint_styles.py` 机检。

## 颜色

| 反模式 | 正确做法 |
|---|---|
| 🤖 硬编码色值（`#0d6a63` / `rgba(...)`） | 用 token：`var(--c-*)` |
| 语义色当装饰（成功色铺成大背景） | 语义色只用于反馈与徽章 |
| 一屏出现 3 处以上强调色 | 强调色一屏 ≤2 处可见 |
| 渐变、霓虹、彩色光晕 | 纯色 + 发丝线 + 留白 |
| **只用颜色承载信息**（红=失败） | 颜色 + 图标或文字，双通道 |
| 纯黑背景（`#000`） | 用偏黑 / 炭灰 / 带色调的深色 |
| 混用冷灰与暖灰 | 灰阶统一一个色温 |

## 排版与间距

| 反模式 | 正确做法 |
|---|---|
| 🤖 硬编码 `font-size: 14px` | 用字号阶梯 token |
| 字号档位无限扩张（十几档） | 收敛到 6–8 档 |
| 全用 400 / 700 两档字重 | 补 500 / 600，层级更细腻 |
| 正文行宽超长（>75 字符） | 限制约 65 字符 |
| 正文行高过密（<1.4） | 1.5–1.6 |
| 🤖 间距随手写（3px / 6px / 7px） | 4 或 8 的倍数；确需微调则记进规范 |
| 全是居中 + 三栏等宽卡片 | 按信息层级安排，别用默认版式 |

## 形状、层级、动效

| 反模式 | 正确做法 |
|---|---|
| 圆角容器漏 `overflow:hidden` | 必须加，否则子元素方角顶破外层圆角 |
| 🤖 手写阴影数值 | 用阴影 token（hover / active / float） |
| 🤖 z-index 魔法数字（9999） | 用层级 token |
| 高度展开用 `max-height` 估算 | `grid-template-rows: 0fr → 1fr` + 子元素 `overflow:hidden` |
| 重复定义同款 `@keyframes` | 复用已有的 |
| 动效 >300ms、或所有元素都动 | 150–300ms，只动解释状态变化的地方 |
| 用力过猛的缓动（bounce/elastic 满地跑） | 弹性只在勾选/开关这类小反馈上用 |
| 层级深度跳变（亮页面里突然一块纯黑） | 同色系内做深浅，别突然跳到另一个色系 |

## 交互与反馈

| 反模式 | 正确做法 |
|---|---|
| 原生 `alert / confirm / prompt` | 用项目统一的反馈组件 |
| 异步操作静默等待（点了没反应） | 按钮 loading + 禁用 |
| 首屏空白、列表空无提示 | 空态：图标 + 一句话 + 主 CTA |
| 数据加载用 spinner 且全屏遮挡 | 用骨架屏，保留布局 |
| 破坏性操作单击即生效 | 二次确认 |
| 错误提示只写"操作失败" | 说明原因 + 可执行的建议 |
| 表单校验错误只在页顶汇总 | 内联到出错字段旁 |
| 敏感值明文展示（token / key） | 默认掩码 + 显示切换 |
| 设置改动既不自动保存也无"未保存"提示 | 二选一，必须有一个 |

## 结构与内容

| 反模式 | 正确做法 |
|---|---|
| 空状态只写"暂无数据" | 给下一步动作的引导 |
| 数据被筛选为空时留白 | 同样给空态 |
| 不可交互的统计也做成卡片 | 能下钻的才做卡片 |
| 占位内容混进正式界面（lorem / 假数据未标注） | 标注 mock，或换成真实占位文案 |
| 编造数据（假用户量、假评分） | 用真实数据或中性占位块 |
| 重画浏览器外框（假地址栏、假手机壳） | 不做，用户环境已有真实外框 |
| 组件样式与页面样式混在一个文件 | 分开：组件样式 / 页面布局 |

## 怎么用这份清单

1. **写之前**扫一眼，心里有数。
2. **写完**逐条过一遍，对六项自评 1–5 分：主张 / 层级 / 执行 / 具体性 / 克制 / 变化——任一项 <3 先改再交。
3. **交付后**跑 `scripts/lint_styles.py`，机检项必须通过。
4. 每遇到一个"这样写我不满意"的新决策 → **补一条到这里和项目的 DESIGN.md**。规范是长出来的。
