# 日报/周报/月报填写模板（v2 规范）

> 配合 report-writer 技能使用。所有「（）」内为填写说明，生成正式汇报时删除。
> 任何数字、姓名、Bug 等级、延期天数均来自用户真实数据，禁止虚构或占位。

## 责任内联标注速查

```
产出类：【责任人:姓名｜交付:月-日 时:分】＋交付物＋量化标准
计划类：【责任人:姓名｜承诺交付:月-日】＋内容＋交付物
多人协作：【责任人:甲+乙｜交付:月-日 时:分】
```

## 日报模板（提交：每日 21:00 前）

### 今日核心产出
- （细化到功能点，标注 100%完成/占比）【责任人:姓名｜交付:月-日 时:分】，交付__，标准__
- 示例：完成退款弹窗页面结构开发（100%）【李雷｜交付:08-04 18:00】，交付可交互页面，UI 1:1 还原、无报错

### 进行中未完成工作
- （内容+进度）【责任人:姓名｜预计:月-日 时:分】，剩余__

### 卡点与阻碍（核心）
- 分类(技术/对接/需求/资源) + 是否需协助 + 对接人 + 期望解决时间 + 影响(约 N 天)
- 示例：接口格式不统一致前端渲染异常，需后端 XX 协助 12:00 前修复，影响页面开发约 0.5 天

### 明日工作计划
- （内容+交付物+标准）【责任人:姓名｜承诺交付:月-日】
- 示例：完成退款需求文档终稿【张昆｜承诺交付:08-05】，交付 docx，可直接评审

### 失误与影响（核心必填）
- 返工:N ｜ Bug:P等级 xN【责任人:姓名｜根因:__｜已修复:是/否｜回归:有/无】；或显式填"无"
- 示例：返工:0｜Bug:P3 x1【李雷｜根因:分页参数未校验｜已修复:是｜回归:无】

### 异常与需协调事项
- （需求变更、临时会议、跨部门对接）

### 个人复盘与思考
- （当日问题、个人短板、即时改进）

## 周报模板（提交：每周六 21:00 前）

### 本周工作总结
- **本周工作复盘**：计划 N 项单日任务，完成 N 项，滞后 N 项
- **项目进度排期跟进（含偏差天数）**：【计划:月-日｜实际:月-日｜偏差:N天｜原因:__｜影响:__】
  - 示例：退款模块进度 90%，较排期滞后 0.5 天【计划:08-08｜实际:08-09｜偏差:1天｜原因:字段对齐争议｜影响:联调顺延】
- **本周卡点问题汇总**（未解必填影响）
- **技术/方案沉淀**
- **本周亮点与不足**（不足剖真实根因）
- **失误与影响汇总（核心必填）**：
  `返工率:__%(__/__)｜Bug:__｜延期合计:__天｜时间浪费:__人时(__)｜交付影响:__`
  - 示例：返工率:8%(1/12)｜Bug:P1x1【张栋栋｜根因:参数边界未校验｜已修复:是】P3x2【李四海｜样式错位｜已修复:是】｜延期合计:1天｜时间浪费:4人时(返工)｜交付影响:导出模块延期1天已追回

### 下周规划（核心）
- **下周排期**（100% 拆解至工作日，含承诺交付）：周一：__【责任人:姓名｜承诺交付:月-日】
- **资源协助需求**

### 个人复盘与思考
- （周度深度复盘：工作习惯、排期能力、协同效率、能力短板）

## 月报模板（提交：月末最后工作日 18:00 前）

### 月度核心成果总结（量化）
- 迭代数 / 需求落地数 / bug 修复数 / 优化成果
- 示例：本月完成 2 轮迭代，落地 18 个需求，修复线上 bug 6 个

### 月度进度整体复盘
- 对照每日任务校验达标率（原计划天数 / 逾期天数 / 当前进度）
- 示例：整体交付率 92%，逾期 3 天，原因为月初拆分粗放

### 系统性问题复盘
- 区分偶发/高频/系统，给根治方案
- 示例：高频：需求不清晰致反复联调；根治：评审前输出细节清单

## 合规自检清单（生成前逐项确认）

- [ ] 每条产出/计划末尾有【责任人:姓名｜交付/承诺交付】
- [ ] 最小颗粒度 = 1 天，无跨天笼统排期（无"2/3/5 天"）
- [ ] 每项任务四要素齐全（执行内容 + 交付物 + 交互结果 + 量化标准）
- [ ] 失误栏已填（含显式"无"），无"正常推进/暂无问题/一切正常"敷衍话术
- [ ] 有返工/Bug/延期/时间浪费均量化，且含责任人 + 根因
- [ ] Bug 五要素齐全（描述 + 等级 + 责任人 + 是否修复 + 是否回归）
- [ ] 延期含具体偏差天数，非"略有滞后"
- [ ] 时间浪费格式含：N 人时 + 来源 + 归属
