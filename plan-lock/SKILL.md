# 方案主题锁定

独立的锁定操作 skill。**这是唯一能够锁定主题的入口**，其他 skill（包括 `plan-execution`）均不得创建 STATUS.md。

---

## 工作流程

```
1. 查找待锁定主题 → 2. 确认锁定 → 3. 创建 STATUS.md 并重命名文件夹
```

---

## 第一步：查找待锁定主题

在 `Plans/` 目录下查找所有主题文件夹，按日期排序，定位**最新的、含有 COMPLETED.md 且尚未锁定**的主题。

锁定判断：
- 存在 `STATUS.md` → 已锁定，跳过
- 不存在 `STATUS.md` → 待锁定

注意：文件夹名中即使已经带有 `[LOCKED]` 前缀，也**不能**单独作为锁定判断依据；真正的锁定判断仍然只看 `STATUS.md` 是否存在。

如果找不到待锁定主题：
- 向用户说明"当前没有待锁定的方案"
- 提示可能原因：尚未执行开发 / COMPLETED.md 未生成 / 所有主题均已锁定

---

## 第二步：确认锁定

向用户展示待锁定主题的摘要：

```
即将锁定主题：{主题名称}
路径：{文件夹路径}
锁定后文件夹名：{YYYY-MM-DD}-[LOCKED]-{主题简短slug}
包含文件：
  - execution-plan.md  （执行方案）
  - COMPLETED.md       （执行结果）
  - UNEXECUTED.md      （未执行/遗留事项）
  - ...（其他文件）

确认锁定后，以上文件均不可再修改。确认吗？
```

如果用户表达"等等"、"再改一下"等，则取消锁定，告知用户可继续修改。

---

## 第三步：创建 STATUS.md 并重命名文件夹

用户确认后，在主题文件夹中创建 `STATUS.md`：

```markdown
# 状态：已执行

> 执行完成时间: YYYY-MM-DD HH:MM
> 此文件夹中的文件不得再修改。
> 任何延续讨论或后续版本开发，请创建新的主题文件夹。
```

然后将主题文件夹重命名为：

```text
{YYYY-MM-DD}-[LOCKED]-{主题简短slug}
```

例如：

```text
2026-06-04-[LOCKED]-threejs-b-side-color-config
```

**锁定后规则：**
- 不允许编辑该文件夹中的任何文件
- 新讨论 → 创建新主题文件夹
- 新主题应继承 `UNEXECUTED.md`
- 文件夹名前缀 `[LOCKED]` 仅用于更直观地显示锁定状态，**流程判断仍然只以 `STATUS.md` 是否存在为准**

---

## 与其他 skill 的关系

| skill | 行为 |
|-------|------|
| `plan-discussion` | 发现最新主题已锁定 → 新开主题，继承 UNEXECUTED.md |
| `plan-execution` | 执行开发 + 产出 COMPLETED.md / UNEXECUTED.md 草稿 → **不锁定**，提示用户使用本 skill 锁定 |
| **`plan-lock`（本 skill）** | **唯一可创建 STATUS.md 并执行锁定重命名的入口** |

---

## 触发示例

以下说法都应触发此 skill：

- "执行完成"
- "确认完成"
- "本主题完成"
- "锁定主题"
- "可以锁定了"
- "就这样吧"
- "没问题了，锁吧"

**反例**（不应触发）：
- "开始执行" → `plan-execution`
- "讨论方案" → `plan-discussion`
