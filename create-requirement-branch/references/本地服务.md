# 本地服务（创建分支 · 内附模块）

本模块是 `创建分支` 技能的组成文件。本地 dev server 统一由**工作区 `dev` 指令**托管（实现源 `<工作区根>/ops/svc.sh`，入口 `ops.sh` 装载后任意目录可用）。**2026-10-14 起本技能不再自养 pm2 模板**——一条龙脚本起服务就是调 `dev <完整分支名>`，端口、进程名、多网卡地址、依赖安装、端口占用复用全部以 svc.sh 单一实现为准，本文件只记口径与日常口令。

> 为什么单一实现：2026-10-13 U3042 errored 复发根因——同一件事两套实现（svc.sh 修了 bash 包装，技能脚本模板没同步），必然漂移。从此改口径只改 svc.sh。

## dev 指令速查（agent 与用户都可直接敲）

| 指令 | 作用 |
|---|---|
| `dev <id后4位>` | 定位 `Apps/` 下对应需求 worktree，pm2 托管启动（缺依赖自动 install；命中多个目录会列候选让消歧）——**一条龙脚本起服务就是调它** |
| `dev <完整分支名>` | 命中多个目录时（如同需求已建 To-test）用分支名消歧 |
| `stop <id后4位>` | 停服务（留档，可再拉起） |
| `del <id后4位>` | 彻底删除进程；要再起就重新 dev |
| `list` | pm2 在册进程 + 完整需求标题 + 端口 总览 |

## 口径（实现源 ops/svc.sh，改口径改那边，本文件不展开）

- **端口 = 需求 id 后 4 位**（2026-10-14 起去掉仓库位前缀数字；同一需求永远同一地址）
- **pm2 进程名** = 纯 ASCII 定长短名，全机常驻；用户随时自己 `pm2 ls` 查、`pm2 stop` 关，不必经过 agent
- **汇报地址 = 所有 en* 物理网卡 IPv4 逐行给**（多网卡机器如 Wi-Fi + 有线各一个，不同设备可能只通其中一个；不用 utun/代理/VPN 虚拟网卡），一个都没有才回退 127.0.0.1
- **`--host 0.0.0.0` 必带**——保证手机 / 别的机器通过局域网 IP 可访问

## 沙箱注意

agent 调 `dev`（含一条龙脚本内部调用）必须**沙箱外运行**——pm2 要写 `~/.pm2`（socket / 日志 / pids），沙箱白名单外会报 EACCES。

## 报错即上报（2026-10-13 用户口径）

`dev` / `stop` / `del` / `list` 任何报错：**原始报错原样转述给用户**，不检索、不排查、不修复——svc.sh 由用户优化。
